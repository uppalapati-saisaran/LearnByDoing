(d) Kernel memory access.

(a) compile with compilers. execute the program on other processer which doesn't support some of the instrutions.

what information a coredump file contains:

   --> Set of pending signals.

   --> State in string like, R,S,Z ...
   --> Whether the process is in Zombie state.
   --> Nice value of the process
   --> process flags
   --> pid, ppid, ....
   --> process name
   --> Command line arguments of the program
   
3) Thread specific Info :
    --> Process status for the thread.
	
4) Info of Memory Mapped files:
   --> Number of files mapped, Name of files mapped, Start address and End address.
   
5) Process Address Space:
   --> Like data segment, stack segment, code segment and heap
