
Real-World Threading Project: Real-Time Logger System 

Use Case:

Mutliple sensors (simulated) generate data at random intervals.
Each sensor runs in its own thread, and the data is logged concurrently to a shared location. 

This mimics:

- Real time log aggreation 
- Server monitoring 
- Hardware device data capture 
- Application telemetry 

What We'll Cover:

Concept - Why It's Important 

Thread - Each Sensor runs independently 
Lock - Prevent log collisions 
current_thread() - See which sensor is active 
sleep - Simulate real-time arrival 
join() - Main waits until all sensors finish logging 

import threading
// threading: to create and manage threads 
import time 
// time: to use sleep() (simulate delay) 
import random 
// random: to add variability in delay (like real-world devices) 

# Shared log file 
log_file = [] 
// Acts like a file where all sensors write their data. Shared among all threads. 

#Lock to protect shared log 
log_lock = threading.Lock() 
// Ensures only one sensor thread writes to log_file at a time, avoiding corruption 

#Each sensor writes 3 data points with delayy 
def sensor_logger(sensor_id):
// Function that each sensor thread runs. sensor_id tells which sensor it is. 
    for i in range(3):
	// Each sensor logs 3 readings (loop runs 3 times). 
	    data_point =  f"Sensor-{sensor_id} - Reading {i+1}" 
		// Creates the actual reading data like "Sensor-2 = Reading 1"
		time.sleep(random.uniform(0.5,2)) # Simulate sensor reading delay 
		// Random delay between 0.5 and 2 seconds
		// Simulates a sensor waiting for the next reading 
		
		#Lock the log file for safe write 
		with log_lock:
		// Begins safe zone where only one thread can enter 
		     log_file.append(f"[{threading.current_thread().name}] {data_point}")
			 // Appends the log with the name of thread writing it. 
			 print(f"[{threading.current_thread().name}] Logged: {data_point}") 
			 // Prints what was logged to terminal for visibility.
		
#Create 5 Sensor threads 
threads = [] 
// To store all sensor threads so we can join them later. 

for sensor in range(1,6):
// Loop to create 5 sensors (Sensor-1 to Sensor-5)
    t = threading.Thread(target=sensor_logger, args=(sensor,), name=f"Sensor Thread-{sensor}") 
	// Create a thread that runs sensor_logger(sensor_id)
    // name = assigns readable thread names 	
	t.start()
	// Starts the sensor thread - runs in background 
	threads.append(t) 
	// Save the thread to wait on it later 
	
#Wait for all sensors to finish 
for t in threads:
  t.join() 
// Ensures main thread waits until all sensors finish logging. 
  
print("\n Final Log:")
for entry in log_file:
    print(entry) 
// After all threads are done, the full shared log is printed.
